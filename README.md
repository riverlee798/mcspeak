# mcspeak · 麦麦替你说

**帮不会中文的外国人在中国麦当劳点餐。** 用他的母语推荐和改单，自动算券，生成「中文在上、他的语言在下」的双语卡片——柜台卡、待付款卡、取餐卡、地图卡。

> 参赛作品：**麦当劳程序员创意开发大赛** · **WaytoAGI 1024 用餐赛道**
> 形态：WorkBuddy Skill（本仓库即技能目录）· 底层能力：麦当劳中国官方 MCP（`mcd-mcp`）

---

## 一句话

外国人走进麦当劳，用母语说完"我要一个不辣、不要生菜、不要冰的可乐"，然后举着一张卡片给店员看，就能吃到。

---

## 要解决的问题

**很多外国人走进麦当劳，在柜台前因为说不出来而离开。**

- 菜单、点餐机、订单页全是中文；麦当劳 App 只有中英文，不会英语的人（阿拉伯语、俄语、西语游客）连"去支付""请取餐"都不认识。
- 点餐要求中文交互：说"堂食还是外带""要加大的吗""要不要加 2 块换购"，一句听不懂就卡死。
- 饮食限制更危险：清真、过敏、不吃猪肉，说错一次就是真问题。
- 现有翻译 App 只能翻句子，**不认识麦当劳的菜单结构**：不知道套餐能换什么、饮料能不能去冰、券能不能用、取餐码在哪看。

mcspeak 不做"翻译"，做**点餐这件事本身**：它真的会调麦当劳的接口下单、真的会算券、真的会生成店员看得懂的卡片。

## 核心功能

| 功能 | 说明 |
|---|---|
| **母语推荐和换餐** | 从 93 个商品里按口味、预算、饮食限制筛 3–5 个，按「① 主食/套餐 ② 小食 ③ 饮料」逐格给出，每格附 2 个可换选项和差价 |
| **真实改单** | 去生菜、去冰、去芝士、去酱——用运行时 `query-meal-detail` 的 `selectedKey`/`unselectedKey` 写进订单参数，**不是写在纸上** |
| **自动算券** | 领券 → 查本店可用券 → 逐张挂到商品行试算 → 失败就摘掉重算 → 报实付最低价；券没生效就如实说"X 月 X 日起可用，今天按原价" |
| **饮食限制（按名称）** | 清真三档过滤、含猪肉直接排除、过敏只做风险提示；**明确说明麦当劳中国不提供清真认证、接口没有过敏原数据** |
| **双语配对卡片** | 四张卡：柜台卡（给店员指）、待付款卡（App 优先）、取餐卡（超大取餐码）、地图卡（给出租车司机）。每块中文在上、他的语言在下，横屏自动两栏对齐 |
| **线上下单** | 到店自取，`calculate-price` 核价 → `create-order` → App「去支付」或支付链接 → `query-order` 拿取餐码 |
| **导航** | 高德（首选）/ 腾讯（备选）/ 谷歌（注明国内偏移）+ 内联二维码 + 给司机的中文地址 |

## 真实测试记录

**2026-10-24，济南，麦当劳济南山大路(成大高科)餐厅。**

一位阿拉伯语用户完整走通全流程：用阿拉伯语说出需求 → mcspeak 推荐并改单（去生菜、可乐去冰）→ 线上下单 → 在麦当劳 App 里用黄色「去支付」按钮完成付款 → **生成双语取餐卡，到柜台出示并成功取餐一份经典麦旋风**。

同期还验证了完整失败路径：未付款订单 15 分钟后自动关闭（状态「订单已取消」），以及券未到生效日时 `calculate-price` 直接报 `600012`（整单失败而非静默忽略）。

> 出于隐私，订单号、取餐码、支付单号、支付链接一律不公开；`references/samples/` 中的真实返回已做脱敏（见[安全检查](#安全检查)）。

## 安装方法

### 1. 配置麦当劳 MCP 连接器

在 WorkBuddy 的**连接器管理**里添加 `mcd-mcp`（麦当劳中国官方 MCP），或在 `~/.workbuddy/mcp.json` 里加入：

```jsonc
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "http",
      "url": "${MCD_MCP_URL}",
      "headers": { "Authorization": "Bearer ${MCD_MCP_TOKEN}" }
    }
  }
}
```

仓库里给了模板 `mcp-config.example.json`，**只放环境变量占位符，不含任何真实 Token**。填好环境变量后重启 WorkBuddy。

> 为什么需要它：菜单、门店、券、下单、订单状态、取餐码全部来自这套官方接口，没有它 mcspeak 只能做翻译。

### 2. 安装技能

```bash
git clone <this-repo> ~/.workbuddy/skills/mcspeak
# 或者：把本目录整体复制到
#   Windows: C:\Users\<you>\.workbuddy\skills\mcspeak
#   macOS/Linux: ~/.workbuddy/skills/mcspeak
```

目录结构（`SKILL.md` 必须在根）：

```
mcspeak/
├── SKILL.md                 技能主文件（S1–S15 全流程）
├── references/              6 个参考文件 + 22 个真实样本
├── templates/               4 个卡片模板（单文件 HTML）
├── scripts/                 render_card.py · demo.py · check_privacy.py
├── examples/                三语示例卡（可直接打开）
├── docs/                    GitHub Pages 用（三语卡片 + 入口）
└── data/                    运行时偏好（不随仓库提交）
```

### 3. 验证

在 WorkBuddy 新开对话，用任意非中文语言说一句：

```
Макдональдс рядом, помоги заказать
```

或直接说 `McSpeak`。技能列表里应能看到 **mcspeak**。

## 限制说明（请务必先读）

1. **清真只按名称过滤**：接口没有配料表、没有清真标识。mcspeak 只排除名称里含猪肉/培根/猪柳的商品，**不做任何认证背书**，也**不承诺**门店无交叉接触。麦当劳中国**没有提供清真认证信息**。
2. **到店订单不能加备注**：`remark` 字段只在外送场景生效。线上点餐加不了"少放酱""多加洋葱"这类自由文本，只能改官方支持的特调项；做不到的会写进柜台卡的"顾客请求"，并建议改去柜台点。
3. **接口没有过敏原信息**：无麸质、坚果、奶、蛋、大豆等数据一律没有。mcspeak 只按名称做**风险提示**并给一张"我对 XX 过敏，请问这个里面有 XX 吗？"的中文卡，**绝不输出"安全"结论**。
4. **没有门店经纬度**：实测 `query-nearby-stores` 返回 `longitude/latitude` 恒为 `0.0`，所以地图卡用"店名+城市"搜索链接，不显示坐标。
5. **没有地铁/公交数据**：不给具体站名和线路，避免编造。
6. **状态码以实测为准**：`待支付=10`、`订单已完成=40`、`订单已取消=60`；`配餐中`、`请取餐` 尚未实测到，遇到未知状态只意译、不猜。
