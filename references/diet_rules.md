# diet_rules.md — 饮食限制处理规则（清真 / 过敏 / 素食 / 不吃某肉 / 辣度）

> 这份规则决定 mcspeak **能说什么、绝对不能说什么**。
> 它不是"尽量保守"的建议，是硬约束。违反任何一条都算产品事故。

---

## 0. 开场必须说明的四件事

只要访客提到饮食限制（清真 / 过敏 / 素食 / 不吃猪肉牛肉 / 不吃辣），第一次回答时**必须**先说清下面四点，再给推荐：

1. **接口里没有配料表，也没有过敏原信息。** 我们能看到的只有：商品名、价格、分类、以及"能去掉哪些配料"。
2. **麦当劳中国没有提供清真认证信息。** 我们无法确认任何一家门店、任何一款餐品是清真的。
3. **不含猪肉的餐品也可能共用设备。** 同一口炸锅、同一张操作台、同一副夹子 —— 交叉接触无法排除。
4. **所以下面的一切都是"按名称判断"的估计，不是保证。** 最终请以门店和包装标识为准，必要时请店员确认。

> 这四句要用访客的母语说，语气平和，不要吓人，但**不能省**。

---

## 1. 清真（Halal）—— 三档，越往后越严格

访客说 "halal" / "清真" / "Muslim friendly" 时，先问一句：**"您需要哪一档？"**（给三档的选择，让他自己选，不要替他决定）。

### 第 ① 档：严格 —— 排除含猪肉和不确定的

可推荐的只有 `menu_tags.md` 里 **含猪肉=不含 且 肉类≠不确定** 的商品：

- 牛：`1100` 巨无霸、`4648` 不素之霸双层牛堡、`1120` 双层吉士汉堡、`521316` 高达吉士双牛堡、`511782` 芝士安格斯厚牛堡、`9900003586` 双层深海鳕鱼堡（鱼）
- 鱼：`1600` 麦香鱼、`9900005460` 麦香鱼套餐、`9900016058` 鱼排堡开心乐园餐
- 鸡：`1440` 麦辣鸡腿汉堡、`1406` 板烧鸡腿堡、`1450` 麦香鸡、`1700` 麦辣鸡翅、`1401` 麦乐鸡、`521156` 那么大鸡排、`9900005432` 麦麦脆汁鸡
- 无肉：`4810` 薯条、`4437` 玉米杯、`521741` 脆薯饼、全部甜品/饮料/咖啡

**必须排除**：所有标"含"的（猪柳/培根系列，见 `menu_tags.md` 衍生清单）+ 所有标"不确定"的（`9900004064` `9900015568` `9900015602` `9900004066` `9900015730` `9900005321` `9900011056` `9900015151` `9900004236` `9900010110` `9900006957` `9900008746` `9900008747` `9900011126` `9900011123` `9900009245` `9900008752`）。

> 注意：**"不确定"一律当"含猪肉"处理**。宁可少推荐一个，也不能错推荐一个。

### 第 ② 档：再加一层 —— 排除名称或酱料明显含酒精的

在 ① 的基础上，再看商品名与可去掉配料里有没有酒精线索：`酒`、`啤`、`朗姆`、`白兰地`、`红酒`、`威士忌`、`酱`（部分酱料含酒精，**看不出来就不是酒精**，但要提示"酱料成分无法确认"）。

实测本店 93 个商品的名称里**没有**明显酒精词；`烧烤/蜜汁/照烧` 类酱料无法确认是否含酒精 → **列为"无法确认"，由访客自己决定**，不要替他判定"无酒精"。

### 第 ③ 档：最保守 —— 只推荐无肉的

只给：鱼（`1600` `9900003586` `9900005460` `9900016058`）、甜品、饮料、咖啡、薯条玉米杯薯饼。

> 适合"我只要确定没有肉"的访客。同样**排除标不确定的**（`9900008752` 派 —— 馅料不明）。

### 含猪肉的怎么办

**直接排除，不提供"去掉猪肉"。** 理由：
- 猪柳、培根是**主体食材**，不是可去掉的配料；实测 `521730` 的特调里只有"吉士"可去，猪肉本身没有开关。
- 说"可以去掉猪肉"是误导，店员也做不到。

### 绝对禁止出现的表述

| ❌ 禁止 | ✅ 改成 |
|---|---|
| 清真 / 清真认证 / 清真餐厅 | "不含猪肉（按名称判断，未获认证）" |
| Halal / حلال / Halal certified | "no pork by name — not certified" |
| 适合穆斯林 / safe for Muslims / Muslim-friendly | "you may want to check with staff" |
| 不含麸质 / gluten-free | "we cannot confirm allergens — please ask staff" |
| 无过敏风险 / allergy safe | "we cannot guarantee — please ask staff" |
| 纯素 / vegan（除饮料外） | "no meat by name, shared fryers possible" |

## 2. 过敏（Allergen）—— 不做"安全"判断

**核心原则：我们永远不说"这个你可以吃"。我们只说"这个名称里明显含 X，建议避开"和"这个要问店员"。**

### 可以做
1. **按名称明显相关的直接排除**（并说明为什么排除）：

| 过敏原 | 名称线索 | 本店涉及商品（示例） |
|---|---|---|
| 鱼 | 鱼、鳕鱼、麦香鱼、鱼排堡 | `1600` `9900003586` `9900005460` `9900005413` `9900000893` `9900016058` |
| 麸质/小麦 | 堡、汉堡、面包、薯饼、派、麦旋风（饼干脆）、薯条（裹粉） | 几乎所有汉堡与油炸品 |
| 奶 | 吉士、芝士、奶、冰淇淋、麦旋风、新地、圆筒、卡布奇诺、拿铁 | `1100` `1120` `515837` `9900008745` `9900008754` `507409` |
| 蛋 | 蛋堡、沙拉酱类 | `521730` `9900014838`（猪柳蛋） |
| 大豆 | 酱料、豆浆类 | 无法从名称判断 → 归"可能" |
| 花生/坚果 | 名称中**没有**任何线索 | 只能说"无法判断" |

2. **给一张中文问店员卡**（必须给，不能只给结论）：

> 我对 **{过敏原}** 过敏，请问这个里面有 **{过敏原}** 吗？
> I'm allergic to **{allergen}**. Does this contain **{allergen}**?
> （加到点餐卡最上方，用红框或加粗）

3. 提示共用设备：「油炸类共用炸锅，即使名称里没有，也可能接触到」。

### 不可以做
- ❌ 说"这个不含花生/不含坚果/不含麸质"
- ❌ 说"这个对你是安全的"
- ❌ 用营养成分表推断过敏原（营养表只有能量/蛋白质/脂肪/碳水/钠/钙，**没有过敏原**）
- ❌ 因为"别人吃了没事"就给保证

### 严重过敏（休克史）的处理
如果访客说 "severe" / "anaphylaxis" / "epi-pen" / "会休克"：**不做任何推荐**，直接给问店员卡 + 建议他去柜台当面确认，并说明"我们无法保证"。

## 3. 素食

| 类型 | 能推荐的 | 说明 |
|---|---|---|
| 蛋奶素 | 鱼、甜品、饮料、薯条玉米杯 | 明确告知"薯条与炸鸡共用炸锅" |
| 纯素 | **只有饮料**（可乐、怡泉+C、橙汁、柠檬红茶、苹果汁、锡兰红茶、美式、浓缩） | 甜品含奶、薯条共用炸锅、汉堡包胚可能含奶/蛋 → 全部排除 |

不要出现 "vegan" 用于任何食物，只在饮料上用 "plant-based drink / no animal ingredients listed"。

---

## 4. 不吃某种肉 / 不吃辣

- **不吃牛肉**：排除 `1100` `4648` `1120` `521316` `511782` `511781` `9900003586`…（见 `menu_tags.md` 肉类=牛），推荐鸡、鱼、无肉。
- **不吃鸡肉**：避开"鸡"字系列；推荐牛、鱼。
- **不吃猪肉**：见第 1 节，直接排除"含猪"清单。
- **不吃辣**：**辣度 ≥1 都要提示**（1 = 可能辣或不确定）。避开辣度 2–3：`521952` `9900016073` `9900016309` `1440` `9900005456` `9900000891` `1700` `9900005451` `9900011123`。
  - 特别提醒：**"麦辣"辣、"麦香鸡"不辣、"板烧"不辣** —— 中文一字之差，英文必须写 `Spicy` 或不写。

---

## 5. 绝不推测

- **不根据语言、国籍、口音、姓名、外貌推测宗教或饮食**。
- 只有访客**自己说** "halal" / "vegetarian" / "I don't eat pork" / "allergy" 才启用对应规则。
- 不问 "Are you Muslim?"，只问 "Do you have any food restrictions?"（开放问句）。
- 记录偏好时也只记"用户主动声明的限制"，不记推测。

## 6. 决策树（伪代码）

```js
function filterMenu(menu, prefs) {
  let list = menu;                                  // 93 项
  if (prefs.avoidPork)  list = list.filter(m => m.pork === 'no');        // 'unsure' 也排除
  if (prefs.halalLevel === 1) list = list.filter(m => m.meat !== 'unsure' && m.pork === 'no');
  if (prefs.halalLevel === 2) list = list.filter(m => noAlcoholHint(m));
  if (prefs.halalLevel === 3) list = list.filter(m => m.meat === 'none' || m.meat === 'fish');
  if (prefs.vegetarian) list = list.filter(m => m.meat === 'none' || (prefs.eggsDairy && m.meat === 'fish'));
  if (prefs.vegan)      list = list.filter(m => m.category === 'drink' && m.meat === 'none');
  if (prefs.noBeef)     list = list.filter(m => m.meat !== 'beef');
  if (prefs.noChicken)  list = list.filter(m => m.meat !== 'chicken');
  if (prefs.mildOnly)   list = list.filter(m => m.spice <= 1);
  if (prefs.allergens?.includes('fish')) list = list.filter(m => !/鱼|鳕/.test(m.nameZh));

  // 永远附带
  return { list, disclaimer: t('diet.disclaimer'), askStaffCard: buildCard(prefs.allergens) };
}
```

**关键**：`pork === 'unsure'` 与 `meat === 'unsure'` 在严格档里**必须排除**，这是"宁可少推，不可错推"的落地点。

## 7. 话术骨架（任何语言都要有这三句）

1. 免责：`The app has no ingredient or allergen data, and McDonald's China does not publish halal certification. I can only judge by dish names.`
2. 行动：`Here are options with no pork in the name — please confirm with the staff before ordering.`（同时给中文问店员卡）
3. 兜底：`If you have a serious allergy, please speak to the counter staff directly — I can't guarantee anything.`
